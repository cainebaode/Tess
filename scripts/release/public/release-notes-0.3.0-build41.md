Tess 苔丝 0.3.0（build 41）

- 新增三个语音入口：Fn 基础听写，以及两个可自定义快捷键和绑定提示词的入口。
- 提供自然表达、AI 指令、英文翻译、条理清单等默认模板，可编辑并新建自己的提示词。
- 更新柔雾设置界面与浮窗正文，支持回看实时转写。
- 新增默认关闭的常用词与个人纠正学习：确认真实听错后保存本地记忆，供下一次 Qwen 识别参考；可停用、撤销、删除和清空。
- 修复 Chrome 网页输入框识别准备，小红书搜索框已由用户确认恢复输入；保留微信／ChatGPT 兼容输入和目标变化后的复制回退。

个人纠正学习为试用功能，实际准确率及收益尚未验证；不会训练模型或保存日常录音。读取不到改稿的应用可主动提交。Whisper 暂不使用个人学习提示。

需要 Apple Silicon，macOS 26 或更新版本。基础语音模型随安装包提供。已有版本请先退出 Tess，再覆盖安装；设置、用户模型、权限和引导进度独立保留。

请下载 `.dmg` 文件；Source code 压缩包不包含应用。[使用帮助](https://tess.baode.life/help/) · [隐私说明](https://tess.baode.life/privacy/)

App 与 DMG 已使用 Developer ID 签名并完成 Apple 公证，签名、票据和 Gatekeeper 检查通过；最终 DMG 已经浏览器下载并在本机覆盖安装、启动，原设置与模型保留。
