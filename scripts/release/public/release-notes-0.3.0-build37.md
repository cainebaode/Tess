Tess 0.3.0 · build 37

这次更新把语音入口和提示词整理到一起，让听写、文字加工和日常设置更清楚。

- 三个语音入口：Fn 基础听写，另有两个可自定义按键、分别绑定提示词的入口。
- 提示词库：内置轻量整理、自然表达、AI 任务指令、AI 简洁指令、英文翻译、条理清单、要点摘要和消息润色，可查看示例、编辑、恢复默认或新建。
- 文字服务：提供常用服务商预设和可编辑样例测试；基础听写仍在本机完成，无需 API Key。
- 输入兼容：完善 ChatGPT 桌面版的原窗口输入，补充本机输入诊断；中途操作目标窗口后会改为复制。
- 设置界面：整理快捷键与模板布局，移除深色选中竖线，统一为柔和的奶油白、绿色与轻磨砂层次。

需要 **Apple Silicon Mac、macOS 26 或更新版本**。安装包包含基础离线语音模型。

下载下方 **Tess-0.3.0-build37-arm64.dmg**；GitHub 自动生成的 Source code 不是安装程序。更新前退出 Tess，打开 DMG，将 Tess 拖入「应用程序」并替换。原有设置、提示词、用户模型和引导进度独立保存。

微信与 ChatGPT 桌面版：先点击聊天输入框再录音；中途点击、打字或切换应用，结果改为复制。无法检查输入框类型和光标，请勿用于密码输入。Tess 不自动发送消息。

可选文字处理需自行配置文字服务，相关费用由服务商收取。提示词效果取决于所选模型，重要结果请复核。
