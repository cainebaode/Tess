## 四步人工验收

没有文字 API 时，可先使用免费云端模型：在“设置 → 文字模型”点“免费试用”，登录 [智谱控制台](https://open.bigmodel.cn/console) 创建自己的 API Key，直接填写到 Tess。地址和 `glm-4.7-flash` 已自动填好；点“保存并测试轻量整理”，通过后点“使用并启用轻量整理”。随后可从“最近结果 → 粘贴文字”试用轻量整理、列表和润色，无需录音。

该模型目前由 [智谱官方提供免费调用](https://www.zhipuai.cn/zh/news/148)，仍受限流和账户权限约束；更换模型时须核对计费。待整理文字发往智谱，Key 存在 Tess 的 Keychain 项中。未用用户账户完成联调；免费策略核对日期为 2026-10-09。

1. 在设置中下载一个语音模型。选择本地 Qwen3-ASR 0.6B／1.7B 或 Whisper large-v3-turbo；录一段中文、英文或中英混说，确认原文可恢复。
2. 在文本编辑器输入框定位，用 `Fn` 完成原文听写；`Shift + Fn` 轻量整理、`Control + Fn` 列表整理、`Option + Fn` 自然润色。组合建议先按修饰键再按 Fn。按住说话、松开 Fn 结束，或轻点保持录音、再点结束；轻点可等待模型加载，长按加载时松开会取消。原输入位置有效时直接填入；切换到网页等没有输入框的位置后，检查结果已自动复制，回到输入框按 `Command + V` 即可。取消后不应粘贴或复制迟到结果。所有键位和录音方式可修改。
3. 使用设置中的截图快捷键（默认 `Control + Option + S`，当前用户自定义为 `Shift + Command + A`）截取选区，圈选或添加文字。点击“完成”或按回车即复制图片并收起，也可另存 PNG。最终发送由用户完成。
4. 在文字模型设置中填写 API Key、接口根地址和 Model ID，主动运行可见样例；检查接收域名、正文和用量，再启用整理。测试可能产生服务商 API 费用。也可主动粘贴文字，整理后先预览。

最近结果可通过 `Control + Option + R` 打开。四种语音模式默认直接输出，目标变化或不可输入时自动复制，浮层短暂提示后消失；仍可开启“所有结果先预览”。超时或可疑改写交付原文，候选结果供人工比较。手动粘贴文字和截图说明先预览。

构建 8 增加四种模式的独立快捷键。快捷键固定本次模式，不改变菜单栏的默认模式；整理快捷键需要已通过测试的文字服务。升级保留已有自定义和已清除键位，新键位遇到冲突保持未绑定。按本次交互要求，首次升级关闭旧版“所有结果先预览”，之后自行开启的选择会保留。无需重新下载语音模型；退出旧版后打开更新的 `dist/Tess.app`。

构建 4 修复了模型下载进度一直显示 0% 的问题。下载页现在区分连接、获取清单、传输和校验，并显示已接收容量；网络超时可重试。来源为 Hugging Face，重试复用完整且校验通过的文件，未完成文件重新下载。获取清单后显示实际总大小，所需空间另包含临时文件与预留空间。更新时先退出旧版 Tess，再用 `dist/Tess.app` 替换“应用程序”里的旧版。

构建 6 修复录音启动崩溃：音频回调明确允许在后台线程执行，声音缓存继续通过锁保护。不需要重新下载已有模型。

构建 7 改用 Fn 并补齐快捷键易用性。在“设置 → 通用与快捷键”点击“启用 Fn”，允许 Tess 的辅助功能权限后返回窗口；此权限也用于输入目标识别。若 Fn 弹出表情、切换输入法或系统听写，可通过“键盘设置”将 Fn 单独按键动作设为“不执行操作”，Tess 不自动更改系统设置。仅旧版默认语音组合升级为 Fn，自定义和已清除键位保留。没有 Fn 或不启用权限时，可录入 `Control + Option + Space` 等组合键，也可从菜单栏开始录音。Esc 仅取消当前会话；录入键位时 Esc 退出录入。截图与最近结果继续使用 `Control + Option + S` / `R`。

结果面板的“选择输入位置”会隐藏主窗口：点击目标输入框，在浮层点“确认位置”，检查接收应用后再点“确认粘贴”。没有倒计时；随时可按 Esc 取消。手动粘贴的未处理文字会保存为草稿，重启后可继续。

## 数据与交付边界

录音由本机识别引擎处理。只有用户选用文字 API 时，待整理文字才发往配置的服务；截图不发送给文字模型。API Key 只存入 Tess 专属 Keychain 项；更换服务域名不会携带旧密钥。云端要求 HTTPS，HTTP 仅用于本机回环地址；请求重定向被阻止。

Tess 不在后台读取剪贴板、不扫描其他本机文件、不自动发送消息或执行口述命令。数据默认存于 `~/Library/Application Support/Tess`，最近结果及草稿最长保留 24 小时，可在设置中清除。模型需用户主动下载；用户另存的 PNG 由用户管理。开发运行可通过 `TESS_DATA_DIRECTORY` 指定本项目内的隔离数据目录。

本轮完成 Release 构建、针对性输入/存储/声音/模型恢复检查、原生样板录屏、隔离数据的实际 App 画面，以及本地 Qwen 小模型的合成语音基线。未使用用户密钥执行供应商联调，也未完成真人录音的候选质量排名。SenseVoice 和豆包官方 ASR 尚未接入；三种本地模型仍需人工对照，默认候选不代表评测胜出。实际录音、权限、输入目标与外接屏截图应按以上路径验收，不能以构建通过替代。

需求依据：[首版 PRD](../product/20261007-02-tess-prd.md)。第三方组件的版权与许可保留于应用资源；语音运行库与模型各自的许可另见交付记录。
