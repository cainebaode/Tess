## 八个默认模板

| 模板 | 用途 |
| --- | --- |
| 轻量整理 | 尽量保留原话，清理口头赘词、重复、修正和撤回，补标点与明显语病 |
| 自然表达 | 允许调整句序和衔接，让文字自然、清楚，保留全部有效信息 |
| AI 任务指令 | 复杂任务按实际信息组织目标、要求、约束和完成标准，不凑空章节 |
| AI 简洁指令 | 连续对话中的补充或小任务，整理成一段直接请求 |
| 英文翻译 | 先处理最终意图，再译成自然英文，保留否定、条件、不确定性及代码标识 |
| 条理清单 | 把已有并列事项或明确步骤列清楚，不额外补任务或负责人 |
| 要点摘要 | 压缩长口述，保留核心结论、重要限制及尚未确定的事项 |
| 消息润色 | 生成可直接发送的消息，保留原有语气和立场，不增加承诺或客套 |

所有模板先区分真正的撤回、有效否定、前后对比和引用，再处理表达。只取消某一事项时从需求中移除；整段只包含一个最终取消的事项时，输出简短取消句，避免空结果触发服务的原文回退。例如“买苹果，不买苹果了，再买牛奶”预期为“买牛奶”；仅“我要吃苹果，算了，不吃了”预期为“不吃苹果了”。

AI 模板保留“先分析、别改代码”等范围，不自动添加技术栈、工具权限、期限、指标或任务步骤。关键缺失信息只在会阻止执行或改变范围时转成针对性的确认要求。模板中的示例为设计示意，不是用户所选服务的实测结果。

新用户默认：⇧Fn → 轻量整理，⌥Fn → AI 任务指令。升级时保留原有选择；编辑过的旧条目仍可使用，并同时提供新模板供换绑。
