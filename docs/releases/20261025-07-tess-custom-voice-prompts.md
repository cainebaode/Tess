# Tess build 30：三个语音入口与提示词绑定

日期：2026-10-25。版本：0.2.0 build 30。本轮为本机迭代，已覆盖安装并启动，人工使用验收待用户反馈。

## 最终使用逻辑

- **Fn 语音输入**：固定做基础听写，不使用文字模型或提示词。语音识别仍在本机完成。
- **自定义快捷键 1、2**：分别设置按键和绑定提示词，可使用同一条或不同的提示词，由提示词决定润色、摘要或进一步加工。使用前需要配置并测试文字服务。
- 设置 → 通用与快捷键：集中展示三个语音入口；截图和最近结果保留在“其他快捷键”。菜单同步提供原文和两个自定义入口，不再提供全局整理模式菜单。
- 设置 → 文字模型 → 提示词库：提供自然润色、整理成指令、轻量整理、列表整理、提炼要点五条默认提示词，可改名、编辑、恢复默认或新建。已绑定的提示词须先换绑再删除。
- 点击某个快捷键的“编辑提示词”，直接打开该快捷键绑定的条目。手动文字处理和服务样例测试使用同一组绑定。

新设置默认以 ⇧Fn 绑定自然润色、⌥Fn 绑定整理成指令；两个组合都能改。旧设置会保留已有组合及适用的提示词选择。本机原默认模式为轻量整理，因此当前是 **⇧Fn → 轻量整理、⌥Fn → 整理成指令**。

每次输入使用开始时的设置和提示词快照，修改从下一次会话生效。加工结果遵循提示词；摘要、翻译和重组不会再被旧的缩短、术语或否定数量检查拦回原文。默认提示词仍要求保留事实和限制，原文始终留在最近结果中；服务失败时使用原文。实际加工质量由用户核对。

## 设置迁移

- `shortcutVersion` 升至 3；旧轻量整理和润色的键位迁移到两个自定义入口，旧列表专用键位退出注册，基础听写固定为 Fn。
- 旧的通用要求和三种模式规则合并成对应提示词条目保留，不丢弃用户编辑的内容。旧模式枚举用于兼容已有设置和结果。
- 新增可选提示词库和两个绑定 ID，旧设置可以直接读取；迁移只运行一次。
- 提示词和绑定先持久保存再切换生效。保存失败保留当前内容；禁止空名称、空内容、重复 ID 和删除仍被绑定的条目。
- 本机实际迁移核对通过：语言、录音方式、预览选项、识别语言、模型、麦克风和引导状态保留，截图与最近结果快捷键保留。API 配置文件迁移前后 SHA-256 一致；未重置 Keychain、模型或权限。
