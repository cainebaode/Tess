## 实现范围

- **常用词**：在“设置 → 语音识别”添加、编辑、停用、删除标准写法、释义和常见误写，支持可选场景。初始为空且关闭，最多 50 条；Qwen 上下文最多 2,000 字，只含标准词、释义与场景，不带误写。Whisper 不使用词库提示。录音开始时固定偏好，预览、最终识别及识别重试使用同一份快照。
- **可选校正**：Fn、两个自定义入口分别开关，默认关闭。启用后将完整转写、相关词条及场景发给已配置的文字服务，音频留在本机。校正和模板合并为一次请求，总等待上限 8 秒；未启用校正的自定义任务仍沿用原 60 秒上限。保留用户原有提示词和绑定。
- **修改与候选**：保存 ASR 原文、校正文本、最终输出及修改清单。自动修改必须对应原文中的具体片段、允许词条和明确依据；数字、路径、代码片段、引用及对比受到检查。没有词库依据的普通中文推测仅提供候选；结果面板可主动采用、恢复原文、再次复制或记为常用词。自由翻译和摘要不受近似原文的旧整理规则约束。
- **失败与中断**：结构错误、校验失败、服务不可用或超时均保留原文。处理中可立即“使用原文”；旧任务被取消，新的交付会话仅输出一次。取消和新录音继续阻止迟到结果覆盖。
- **浮窗**：正文 15pt、行距 5pt、视窗 144pt、有效宽度约 348pt，默认约 6 行。面板正常尺寸为 432 × 424pt，屏幕可用区域较小时调整约束。状态、正文、计时和按钮位置稳定；回看暂停跟随，“回到最新”恢复。处理阶段保留草稿，最终显示与交付文字一致。
- **完整预览**：原来只展示最近 12 秒音频的识别结果；现在逐个保留固定的 12 秒预览片段，同一片段内的更新替换旧草稿。停止后仍重新识别完整录音，原有最终识别分块方式不变；不把预览当终稿。
- **输入目标**：浮窗维持非激活窗口。只豁免指向本次浮窗的鼠标／滚动操作；其他窗口操作、打字、应用切换和监控失效仍使兼容输入回退。滚动事件没有鼠标窗口字段，按其实际指针位置查询窗口。

词汇提示可能改善术语，也可能改变其他字词；本版保持主动启用，界面与随包帮助说明了这一点。云端 ASR、跨端词库、更新提醒和新用户招募未进入本轮实现。

## 同录音对照：仅合成冒烟检查

在 Mac15,7、Qwen3-ASR 0.6B 上使用本机 Tingting 合成的 8 条固定录音，覆盖 PRD、token、语音输入、真正的 PLD、偷看了、云输入、自我修正及 22 秒长句。每个条件使用相同 WAV，记录完整摘要；每条运行一次，另记首条冷推理。该组不是 80 条真人开发／保留集，也不是统计准确率结论。

| 条件 | 归一化字符错误／总字符 | 汉字错误／总汉字 | 本次热推理 p95 |
| --- | --- | --- | --- |
| A：无词库，自动语种 | 2 / 208 | 0 / 187 | 0.893 秒 |
| B：词库与释义，自动语种 | 2 / 208 | 1 / 187 | 0.638 秒 |
| A：无词库，中文提示 | 2 / 208 | 0 / 187 | 0.649 秒 |
| B：词库与释义，中文提示 | 2 / 208 | 1 / 187 | 0.658 秒 |
| 额外诊断：仅标准词，自动语种 | 2 / 208 | 1 / 187 | 0.660 秒 |

峰值常驻内存约 811–825 MiB。首条推理另记，不能由一次运行的最大值推断真实 p95 或新增文字模型的等待时间。

具体观察：PRD 从 `T R D` 改善为 `PRD`；token 和“语音输入”在 A 中已经正确。B 仍将真正的 PLD 识别为 `TLD`／`T L D`，并新增“浮窗 → 幅窗”一个汉字错误；“偷看了”和“云输入”的正确含义保留。仅标准词的额外诊断没有消除该汉字退化，因此没有据此删除释义或更改默认语种。

**未达到可宣称通过的识别质量验收。** 小样本汉字错误率上升约 0.535 个百分点，且真正 PLD 的录音仍未识别正确。不能以 PRD 的单例改善宣称解决全部问题，不能用本机 HTTP 替身的校验通过代替文字模型的语义质量。80 条真人语料、开发／保留分组、术语错误减少 40%、零误纠正、真实服务新增等待 p95 ≤ 2 秒，均待独立评测；本轮没有上传录音或接入云端识别引擎。

## 用户集中体验

1. 先保持新开关关闭：试一次短句、一次 30 秒以上口述；中途上滚回看，确认新内容不拉走阅读位置，再点“回到最新”。停止后确认草稿到终稿不闪空、文字只交付一次。
2. 在语音识别设置添加自己的 PRD、token 词条和释义，主动启用词库。分别说产品需求、真实 PLD、“模型的 token 消耗”与“他偷看了我的笔记”，比较实际效果；不理想时可关闭词库。
3. 主动为需要的入口开启上下文校正，使用现有文字服务。查看原文、修改与候选；处理中试“使用原文”或取消，再开始新录音。核对已有快捷键、模板、模型和权限仍正常。
