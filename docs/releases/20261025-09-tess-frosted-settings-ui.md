# Tess build 36 柔雾材质与界面统一

2026-10-25，Tess 0.2.0 build 36 已沿用原 Developer ID 签名、覆盖安装并启动。用户反馈 build 35 的玻璃面板不协调、边缘锐利，本次取消独立玻璃外框，统一为温润的柔雾表面。用户决定保留当前版本，停止继续调整视觉。

## 当前界面

- 移除设置页和弹窗的 Liquid Glass 高反差轮廓与悬浮间距，顶栏直接融入窗口背景。
- 设置页和提示词库的侧栏使用普通薄磨砂，右侧及上下边缘渐隐，不画独立面板边框。
- 减弱背景的绿色和米黄色变化，保留奶油白与森林绿品牌色。
- 共用卡片圆角由 14 调整为 18，取消常态描边并降低阴影强度；系统增强对比度开启时仍保留清楚边界。普通按钮圆角由 8 调整为 10，选中项去掉高光描边。

材质用于衬托内容，当前取舍优先保持各区域协调与文字清晰。参考 [Apple 材质指南](https://developer.apple.com/design/human-interface-guidelines/materials) 关于克制使用玻璃效果、区分导航与内容层的原则。

## 验证与安装

- Release 构建通过，保留项目已有的 Combine 与 AppIntents 警告；修改范围为视图、共用样式和 build 号。
- 保留 Bundle ID `life.baode.tess`、原 Developer ID / Team `9D6XC2T2G5`、Hardened Runtime 和时间戳。候选与安装版严格签名验证通过，35 个载荷文件与最终签名候选一致。
- 七个随包模型文件摘要一致。以录音结束后、安装前的最新偏好作比较，设置、快捷键、提示词和引导状态保留，API 配置摘要不变；未修改权限或 Keychain。
- 等用户当前录音结束后退出 Tess。由于桌面窗口出现其他切换，本次核对应用已退出、旧新载荷路径一致且 build 35 回退存在后，直接复制已签名文件到 `/Applications/Tess.app`，再核对完整载荷与签名。此次是本机迭代，不是最终 DMG 安装验收。

安装后已简短查看“关于”页，确认独立玻璃外框已移除；继续查看时用户再次录音，未继续操作，未保留录音截图。用户反馈“看起来改来改去，又改回去了。整体就就这样吧”，据此停止本轮视觉迭代、保留 build 36，不将此视为功能验收通过。本轮没有公证、DMG、GitHub 同步或公开发布。

## 版本与回退

build 33 整理选中项、卡片和按钮；build 34 统一分隔线与行距，用户反馈玻璃不明显；build 35 改为原生 Liquid Glass，用户进一步反馈整体不协调、边缘锐利。这些版本的构建与签名检查不代表视觉效果已获用户认可。

当前候选为 `.build/local/0.2.0-build36/Tess.app`。build 35、build 34、build 33 与本轮 UI 调整前的 build 32 均保留。当前差异、构建与签名日志、设置保留核对及模型和安装摘要位于本机 `evidence/20261025-soft-material-ui/`；此前材料保留在 `evidence/20261025-glass-visibility/` 与 `evidence/20261025-material-ui/`。
