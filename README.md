# Tess 苔丝

Mac 上的本地语音输入与原位截图标注工具。

- 产品页：https://tess.baode.life/
- 使用帮助：https://tess.baode.life/help/
- 隐私说明：https://tess.baode.life/privacy/
- 下载：在本仓库的 Releases 中选择 DMG 安装包。不要下载自动生成的 Source code 压缩包。
